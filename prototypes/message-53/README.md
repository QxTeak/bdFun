# bdFun 消息二级页面原型

在浏览器打开 index.html。顶部工具栏可直达页面、切换尺寸、深浅色和异常场景。数据及写入均在本地模拟。

| 页面 | 对齐当前实现 |
|---|---|
| 回复与@ | 回复我的 / @我，顶栏下拉直接选择通知偏好、下拉刷新，正文、引用、根评论和通知操作 |
| 收到喜欢 | 最新 / 累计，顶栏下拉直接选择通知偏好、下拉刷新，聚合点赞进入点赞详情，单条点赞回原内容 |
| 系统通知 | 标题、正文内链接、来源和通知操作 |
| 新增粉丝 | 保留现有页面及回关操作，通过原型场景选择进入 |
| 联系人 | 我的关注 / 我的粉丝，仅关注支持搜索，点击联系人进入私信 |
| 私信会话 | 昵称、头像空间入口、设置、消息时间、正文、图片、视频分享、未知类型、撤回、举报和输入区 |
| 聊天设置 | 用户入口、置顶、免打扰、黑名单、适用账号的内容推送 |
| 消息设置 | 服务端提供的设置项及子页、黑名单和屏蔽词 |
| 点赞详情 | 原内容入口及点赞人员 |
| 二级私信列表 | 现行代码支持的服务端入口类型，原型通过场景选择进入 |

消息中心将联系人放在顶栏操作区（Android 使用 Miuix ContactsBook），会话筛选下方直接显示列表。紧凑屏采用设置页同款横向进退场，宽屏仅在详情栏转场并保留 340dp 左栏，双栏阈值沿用 840dp。预览视口选取 390×844、540×720 和 1180×790。头像、内容、服务端设置标题和取值均为示例。进入相邻业务模块的路由以提示演示。

视觉调整集中在二级页。收紧行距与版心，通知按现有分组共用容器，回复中的引用仍在正文下方，右上角更多按钮直接显示通知选项。页签或首条内容初始紧接顶栏，滚动时可进入顶栏后方。列表下拉刷新时，指示器浮在内容上方。

Android 实现使用现有 TeakUI 页壳。通过 `TeakActivityScaffold` 的 `ActivityPageSlots.topBarActions` 放置 `TeakTopGlassButton`，由页壳处理顶栏材质和系统栏。保留现有 `PullToRefreshBox` 刷新入口，刷新中保留列表。

Issue #53 的预览包含置顶状态未知和局部重试，重试恢复为本地示例。实现阶段需向展示层提供独立的置顶读取状态和真实错误，保存失败保留最后确认值。置顶修复仍需同账号验证真实读取、写入及重新进入的一致性。

通知卡片和私信会话长按打开下拉菜单，桌面也可右击。点赞支持关闭或恢复通知及删除，回复和系统通知支持删除。
