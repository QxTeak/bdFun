# 弱网与评论体验修复验证

## 改动范围

- 详情播放器换 CDN/清晰度时保留画面；新视频/分 P 在真实首帧前显示封面。
- 首页按账号和推荐来源保存最近 24 条列表；首屏先读缓存，请求最长等待 12 秒。
- 个人页同步投影进程内旧资料（包括过期缓存），刷新失败保留旧字段；头图优先读取 Coil 缓存，加载期间不清空旧图。
- 图片预览使用独立全屏窗口，评论图片起点从原窗口坐标换算为屏幕坐标。
- 共享富文本入口主动加载表情字典，独立动态详情等入口无需先打开表情面板。
- 主评论与楼中楼输入按内容增长，最多五行；楼中楼显示发送中/失败反馈，20 秒超时解锁，成功后滚动到新回复。

## 自动检查

运行 `:app:assembleDebug`、`:app:testDebugUnitTest`、`:feature:home:testDebugUnitTest`、`:infra:storage:testDebugUnitTest`、`:core:application:test`，另运行 `:danmaku-engine:test`。

新增回归覆盖：首页挂起请求时缓存可见、超时保留缓存；磁盘缓存限额、账号隔离和损坏文件；个人页过期缓存立即显示与失败回退；发送超时反馈、解锁和重试。

当前模拟器没有可用的接口网络；真实登录发送、弱网自动换源及以上未勾选交互仍待装机复测，不将构建通过视为行为验收通过。
