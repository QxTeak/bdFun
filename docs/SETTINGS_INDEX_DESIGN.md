# SET-01 · 结构化设置索引与交互原型

## 本轮范围

先落设置索引后端与 HTML 原型，Android 仍使用现有设置页面。首批覆盖36项现有开关/固定枚举；不是全部设置迁移完成。后续在确认原型后将 Android 列表切换为类型驱动渲染器。

## 索引合同

唯一输入为 `app/src/main/assets/settings-index.json`，顶层是 SettingsCategory 数组；字段沿用 name / route / icon / groups、title / settings 与 pref_name / type / title / subtitle / default。

`select` 补充 `options: [{ title, value }]`，value 是实际持久化值，例如720P为64，绝不是数组位置。当前支持 boolean、string、integer、decimal、string_set、select；类型错误、未知类型、重复键/路由、非法默认值整份拒绝，不部分导入。读取索引不会重置用户旧值。default 用于展示合同及显式单项重置；现有控制器默认值兼容保留，后续迁移需持续核对二者。

存储仍是既有 SharedPreferences 和分组控制器。pref_name 通过显式绑定白名单访问仓储；索引不能执行代码、指定任意文件或直接写用户配置。索引装配在 SettingsStore，纯搜索/验证在 core/domain，JSON 解码在 infra/storage，搜索与值快照为应用层不可变 StateFlow。

搜索按分类名、组名、标题、副标题与持久化键匹配，忽略英文大小写，多词取交集；支持限定 route，空查询返回空结果。结果携带分类、分组和设置，前端据此导航及定位。

## 原型与交互

用浏览器打开 `docs/prototypes/settings/index.html`，无需服务器或外部依赖。数据为资产索引的内联快照，可离线查看。修改索引后须同步快照。

- 横屏：左侧分类及全局搜索，右侧二级设置；搜索按钮仅搜索当前分类。结果跳转后定位对应行。
- 竖屏：一级分类列表，固定底部柔光胶囊；展开时列表淡出上移，胶囊分裂为输入框和关闭按钮。二级页搜索从右上角工具栏进入，结果保留分类范围。
- 原型提供浅色/深色、横屏/竖屏与键盘占位开关；真机浏览器监听 visualViewport。HTML 只是材质/交互预览，正式 Android 使用现有 Miuix/TeakUI 和 IME inset，不把 CSS 当作原生效果验收。
- 返回/关闭保留当前分类，搜索结果有空态，控件具备键盘焦点、语义标签与减弱动画支持。

## 后续待接入

动态 CDN 的候选与测速状态、壁纸系统选择、关于/日志/退出登录等动作不是简单持久化值，需新增 action/provider 合同与宿主白名单。我的页、推荐优化使用独立存储，不能假装都在 settings 文件。弹幕参数滑条仍要保留范围与原节流语义。原型的三级页以固定枚举选项页展示，横屏仍在右栏内推进；正式 Android 的 route/返回栈合同与上述专用行留在下一阶段。

## 验证与交付约束

索引解码测试覆盖默认值、重复项、非法类型、空标题、枚举真实值和范围搜索。应用层测试覆盖旧值保留、写入旧键、旧控制器改动回流及无效写入不落盘。

新 PR 仅包含 SET-01。测试 release 在独立集成分支合入 PR #52 与 #54，不推送 main、不合并远端 PR。APK 不代表新原生设置 UI 已完成。

手动验收：横竖屏分类切换、全局/分类搜索、无结果、结果定位、关闭恢复、键盘弹出与关闭、放大字体、深色与减弱动画。Android 后续接线还需验证主题、播放器/弹幕设置生效与升级保留偏好。
