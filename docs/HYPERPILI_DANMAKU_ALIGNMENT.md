# 弹幕交互增量对齐

参考：AritxOnly/Hyper-PiliPlus `0d08dd25bdeaa9a55e5a0e333154b681fd8048fe`，
`lib/plugin/pl_player/view/view.dart`、`lib/pages/video/widgets/header_control.dart`、
`lib/http/danmaku.dart`、`lib/common/widgets/dialog/report.dart`。

本轮按“已有功能不要大改”约束，只补现有弹幕交互，不替换渲染引擎、设置、筛选或高赞展示规则。

| 交互 | 当前实现 |
| --- | --- |
| 高赞快捷点赞 | 原高赞区域新增独立图标命中区，保留文字/计数绘制和时间窗口/阈值/排序 |
| 点赞/取消点赞 | 共用 application StateFlow；成功后更新，失败不变；同一 CID/ID 请求互斥 |
| 状态与计数 | 本页面内高赞图标、原始服务端计数加本次点赞变化、浮层动作标签同步 |
| 弹幕操作 | 点赞/取消、复制、举报；选中固定及关闭释放沿用已有捕获流程 |
| 举报 | 与参考相同的原因编号，其它必填说明，确认后提交 |

边界：没有新增服务端初始点赞状态查询，不能宣称能恢复其它客户端的点赞状态；
上游 65006/65004 的状态纠正、本人弹幕撤回、时间文本跳转、作者屏蔽未在本轮加入。
这些属于后续独立增量，不以本轮完成宣称全量对齐。

验证：领域/视频/app 单元测试与 Debug 构建通过；新增身份保留及点赞/取消请求顺序检查。
设备回归仍需检查半屏/全屏图标命中、图标和浮层交叉操作、切 P、网络失败、双击/长按/拖动、旋转及画中画。
